# The World Today — 25 November 2026

A newspaper front-page image summing up the world news of Wednesday, 25 November 2026: three tankers hit by mines in the Strait of Hormuz, Ukraine sinking a Russian warship off Libya, the deadly Russian strike near Kyiv, Iraq's seizure order for Kurdish oilfields, and the toll of 700,000 Russian soldiers killed.

## How to run

```sh
python3 -P -s main.py
```

This writes `entry.png` next to `main.py` (and to `/output/entry.png` when `/output` exists). The program uses only the Python standard library and Pillow, loads only the bundled DejaVu fonts in `fonts/`, makes no network calls, and is deterministic — repeated runs produce byte-identical output.
